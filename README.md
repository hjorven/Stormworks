# Ministerium für Seife & Ordnung

Satire-Webseite gegen das Nicht-Duschen beim Stormworks-Spielen. Enthält den Fluchtsimulator (Gregor vs. Dusche, mit Kanalnetz, Brückenbau und Schiffsverkehr), Propaganda-Aushänge, einen Lagebericht, einen Selbsttest und ein Hygiene-Gelöbnis mit druckbarer Urkunde.

Alles nur Spaß. Einfach `index.html` im Browser öffnen.
